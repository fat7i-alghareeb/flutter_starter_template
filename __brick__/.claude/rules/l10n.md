# Localisation (loads when you touch strings)

- Search both `ar.json` and `en.json` for the sentence first; reuse a key. New key: same dotted key in **both**, then
  `dart run tool/generate_app_strings.dart`. Getter = camelCase of the key (`feed.saved` → `AppStrings.feedSaved`).
- The generator refuses: a key in one language only, placeholder counts that differ, one sentence under two keys, a plural group
  without `.other`. Counted sentences are plural groups (`key.one`, `key.other`, …). `{}` = an argument.
- Never `.tr()` outside the generated file; never a literal sentence in a widget (the discipline test fails on Arabic and English).
- Numbers through `AppFormats`. Arabic is the default and the fallback language.
- Do not read `app_strings.g.dart` whole — grep for the key. Do not `dart format` it.

Full text: `.ai/localization-rules.md`.
